2. Core IA Principle

Backend Entity ≠ Navigation Item

هر Entity در Backend نباید الزاماً یک گزینه مستقل در Navigation باشد.

IA باید بر اساس:

User
+
Job
+
Context
+
Action

ساخته شود، نه صرفاً بر اساس Database structure.

20. Workspace ≠ Navigation

«اینجا چه کاری می‌توانم انجام دهم؟»

Map

Map + Layers + Filter + Inspector + Timeline

42. P2.1 Decision Summary

01. IA is user/job driven.
02. Backend entities do not map 1:1 to navigation.
03. Project is a major operational context.
04. Map is a cross-domain workspace.
05. Attachments are cross-cutting evidence objects.
06. Operations groups event/issue domains.
07. Mobile uses My Work as a central mental model.
08. Web uses Workspaces for complex operations.
09. Navigation exposes concepts.
10. Workspaces expose operations.
11. Role-aware navigation is required.
12. Progressive disclosure is required.
13. Search and notifications are cross-cutting capabilities.
14. Deep links must preserve context.
15. Detail views should preserve related-record continuity.
