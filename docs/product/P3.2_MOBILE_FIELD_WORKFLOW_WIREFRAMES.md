---

1. Goal

The goal of P3.2 is to translate the approved interaction architecture from P3.1 into concrete Mobile screen structures and workflow wireframes.

This Gate establishes:

- Mobile screen sequence
- Screen responsibilities
- Navigation between screens
- Primary actions
- Context visibility
- Field workflow structure
- GNSS interaction placement
- Dynamic Form placement
- Attachment interaction placement
- Draft and Resume behavior
- Offline and Sync visibility
- Error and recovery placement

P3.2 is a wireframe and interaction architecture Gate.

It is not the final visual design.

---

2. Relationship to Previous Gates

The Product Design sequence is:

P1 — Product / UX Discovery
        ↓
P2 — Information Architecture
        ↓
P3.1 — Core UX Flows & Interaction Architecture
        ↓
P3.2 — Mobile Field Workflow Wireframes
        ↓
P3.3 — Web Command Center & GIS Wireframes
        ↓
P3.4 — Forms / Attachment / Offline / Sync Wireframes
        ↓

        ↓
P3.6 — P3 Consolidation & Design Gate

P3.2 therefore does not redefine the Product Model or Information Architecture.

It translates the already approved model into Mobile screen structures.

65. P3.2 Decision Gate

The following decisions are accepted:

1. Field Visit is the primary Mobile wireframe workflow.
2. Home is action-oriented.
3. My Work is the central operational Mobile workspace.
4. Project Context remains visible.
5. GPS is part of the workflow, not an isolated utility.
6. Dynamic Forms remain runtime-driven.
7. Observations are contextual to operational work.
8. Attachments are evidence and retain parent context.
9. Review occurs before completion where appropriate.
10. Offline save is a normal operating behavior.
11. Drafts are first-class.
12. Resume restores workflow context.
13. Sync is a visible operational capability.
14. Map is a field workspace.
15. Incident → Action → Verification remains continuous.
16. Primary actions are state-aware.
17. Errors provide recovery paths.
18. RTL-first design remains active.
19. Light-first + Dark support remains active.
20. Mobile does not copy Web navigation.
