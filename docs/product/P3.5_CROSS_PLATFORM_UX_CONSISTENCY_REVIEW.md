1. Goal

The goal of P3.5 is to review and validate the consistency of the GeoField UX across Web and Mobile.

The objective is not to make Web and Mobile visually identical.

The objective is to ensure that both platforms represent:

- The same Product
- The same Domain Model
- The same Object meanings
- The same Project Context
- The same Workflow semantics
- The same State semantics
- The same Evidence semantics
- The same Verification concepts
- The same Permission meaning

while preserving platform-specific UX.

The governing principle is:

One Product
+
Shared Semantics
+
Shared Context
+
Platform-specific UX

51. Cross-Platform Anti-Patterns

Anti-pattern 1

Mobile and Web use different meanings for "Completed".

Anti-pattern 2

Uploaded on Mobile is interpreted as Verified on Web.

Anti-pattern 3

The same Incident has different state semantics on each platform.

Anti-pattern 4

Project context changes silently between platforms.

Anti-pattern 5

Attachment appears under a different parent object.

Anti-pattern 6

A Form field is required on one platform but semantically optional on another.

Anti-pattern 7

A permission is available on one platform while being semantically denied on another without explicit product reason.

Anti-pattern 8

Platform-specific UI decisions alter the underlying Product workflow.
