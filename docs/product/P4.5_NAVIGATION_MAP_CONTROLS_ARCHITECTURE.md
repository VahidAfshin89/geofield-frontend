1. Gate Objective

P4.5 با هدف تعریف معماری Navigation و Map Controls برای GeoField انجام شد.

P4.2 سیستم Color و Semantic Tokenها را تعریف کرد.

P4.3 Typography، Spacing، Sizing و Layout System را تعریف کرد.

P4.4 معماری Core Components را تعریف کرد.

P4.5 این Foundations را در دو ناحیه حیاتی محصول به هم متصل می‌کند:

Navigation
+
Map Interaction

هدف این Gate تعریف یک معماری منسجم برای:

- Web Navigation
- Mobile Navigation
- Workspace Navigation
- Context Preservation
- Map as Primary Interaction Surface
- Map Controls
- Layers
- Basemap
- Search
- Filter
- Selection
- Feature Inspector
- Current Location / GNSS
- Spatial Interaction
- Measurement
- Map State
- Offline Map Context
- RTL/LTR behavior
- Accessibility
- Web/Mobile adaptation

است.

P4.5 هیچ Map Engine مشخصی را Freeze نمی‌کند و هیچ Implementation Production در Flutter، React یا Next.js ایجاد نمی‌کند.

4. Navigation Architecture

Navigation سه سطح دارد:

Global Navigation
        ↓
Workspace Navigation
        ↓
Object / Context Navigation

Global Navigation

ورود به حوزه‌های اصلی محصول.

Workspace Navigation

ورود به کار جاری و ابزارهای مربوط به آن.

Object / Context Navigation

حرکت میان Detail، Related Records، Map Context، Actions، Evidence و History.
